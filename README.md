# Pesca esportiva no Ceará

Landing page em HTML, CSS e JavaScript, sem dependências.
Marca: **Pesca Extrema**, com a logo original fornecida pelo proprietário.

## Cores da operação

| Uso | Cor |
| --- | --- |
| Principal / azul marinho | #1D335E |
| Botões e destaques / laranja | #FF8515 |
| Apoio / azul claro | #A5D9F5 |

A logo está em assets/logo-pesca-extrema.png e foi preservada sem alterar o desenho.
Ela aparece no menu, no rodapé e no favicon.

## Como abrir

Abra index.html no navegador. Mantenha a pasta assets junto aos arquivos.

## Como personalizar

- config.js: nome da operação, WhatsApp verdadeiro e redes sociais.
- index.html: pacotes, duração, inclusões e textos.
- assets/: substitua as imagens ilustrativas por fotos autorizadas da operação.
- COPY.md: sugestões dos textos para as seis seções.

O WhatsApp está vazio. Sem um número, o formulário prepara uma mensagem para
copiar e não envia visitantes a um telefone fictício. Use 55 + DDD + telefone.

A foto do topo é a imagem original fornecida pela operação, preservada em
assets/topo-pesca-extrema.png. A foto preenche todo o topo, incluindo atrás do menu. A paisagem e as imagens da galeria são ilustrativas,
geradas por IA. Os pacotes são sugestões editáveis.
Não há depoimentos, avaliações ou métricas de clientes inventados.

## Arquivos

index.html, styles.css, script.js, config.js, assets/ e COPY.md.

## Recursos

Menu com letras de 16px (1rem) no celular e no computador, com espaçamento ajustado.

Menu fixo glassmorphism, rolagem suave, parallax, filtro de espécies, galeria
ampliável e mensagem de reserva com a espécie e o pacote selecionados.

O parallax respeita movimento reduzido e é desativado no celular. O formulário
não armazena dados nem envia mensagens automaticamente.

## Enviar este projeto ao GitHub

Crie um repositório chamado pesca-esportiva-ceara, preferencialmente privado.
Extraia o ZIP, abra a pasta pesca-esportiva-ceara e envie o conteúdo dela pela
opção de envio de arquivos. Em um repositório vazio, use uploading an existing file;
se já houver arquivos, use Add file > Upload files. Envie também a pasta assets
e confirme o envio/commit.
Não envie apenas o ZIP: o repositório deve conter o código e as imagens.

Criar o repositório salva o código. A hospedagem da página é uma etapa separada.
Se publicar em um domínio próprio, acrescente o endereço real às metatags
og:url, og:image e canonical de index.html.
